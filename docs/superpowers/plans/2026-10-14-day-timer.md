# Day Timer + Installable App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a Weave user track their workday live (start day, switch between items, pause, away detection) from an always-on-top Edge mini window, then review and send the day as normal work-log entries; make Weave installable as an app.

**Architecture:** All timing logic is a pure, unit-tested module (`lib/dayTimer.ts`) that stores timestamps and derives durations. A React hook persists that state to `localStorage` per user and wires heartbeat, idle detection and a single-tab owner lock. UI components render the panel in the user screen and the same tree into a Document Picture-in-Picture window via a React portal. Work-log saving is extracted from `app/page.tsx` into `lib/worklog.ts` so the form and the timer share one implementation.

**Tech Stack:** Next.js 14 (app router, client components), React 18, TypeScript, Supabase JS, lucide-react, Vitest (new, unit tests only), sharp (new dev dependency, icon generation only).

**Spec:** `docs/superpowers/specs/2026-10-14-day-timer-design.md`

## Global Constraints

- Target: installed Weave app in **Microsoft Edge on Windows**; the mini window uses **Document Picture-in-Picture**; hide "Pop out" when `window.documentPictureInPicture` is missing.
- The running day is stored **only in `localStorage`** under `weave.dayTimer.<userId>` until sent. No new database table, no new migration.
- Rounding: per item, total ms of the day → `Math.round(hours * 2) / 2`. Rows that round to 0 are not saved unless edited.
- Away threshold **10 minutes** (`AWAY_THRESHOLD_MS = 10 * 60_000`); heartbeat **30 s** (`HEARTBEAT_MS = 30_000`); Idle Detection threshold **60 s** (API minimum).
- The day belongs to the **local** date "Mulai hari" was clicked (`localDateStr`, not `toISOString`).
- Mini window size `{ width: 320, height: 420 }`.
- Labels: keep "Tambah Proyek"; the mini window add button is "+ Tambah".
- Before the v4 database script runs (`hasV4Schema === false`) only the Project category is offered, everywhere.
- Styling: reuse existing tokens and classes (`worklog-*`, `entry-row`, `field-input`, badges, `btn-*`); new classes only for timer layout. Light and dark (`:root[data-theme="dark"]`) must both work.
- i18n: every new string goes into both `text.id` and `text.en` in `app/page.tsx`.
- Package manager: pnpm 9 (`pnpm-lock.yaml`). On this machine pnpm is invoked as `npx -y pnpm@9 <args>`; the plan writes `pnpm <args>`.
- Build check: `NEXT_PUBLIC_SUPABASE_URL=https://xfbvrndsolancoscebjy.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=build-placeholder pnpm build` must pass.
- `app/page.tsx` may only export the default page component (Next.js rule). Shared code lives in `lib/` and `components/`.
- Files in this repo use CRLF in the working copy (`core.autocrlf=true`); scripted edits must normalise `\r\n` before matching.

## Review Focus

1. **Laptop sleeps (or Weave is closed) while a timer runs** → on wake/reopen the user gets one away prompt starting at the last heartbeat, not silent hours on the item. Test: Task 3 "sleep gap".
2. **Screen locked, then the PC sleeps overnight inside the same day** → one prompt covering the whole span from the lock, not two prompts or a gap starting at wake. Test: Task 3 "idle then sleep".
3. **Timer left running past midnight / day never sent** → next morning the old day is closed at its last heartbeat and opened in review; the new day does not inherit it. Test: Task 4 "stale day".
4. **Corrupt, old-version or another user's data in `localStorage`** → ignored without crashing; the panel shows "Mulai hari". Test: Task 4 "loadState rejects".
5. **Early morning in Jakarta (00:00–06:59 local)** → the day is today's local date, not yesterday's UTC date. Test: Task 2 "localDateStr uses local time".

```ts
import type { SupabaseClient } from '@supabase/supabase-js';

export type WorkCategory = 'project' | 'quotation' | 'training';
export const WORK_CATEGORIES: WorkCategory[] = ['project', 'quotation', 'training'];
export const CATEGORY_LABEL: Record<WorkCategory, string> = { project: 'Project', quotation: 'Quotation', training: 'Training' };

export type Project = { id: string; project_code: string; name: string; company?: string; description: string; is_active: boolean; inactive_from: string | null };
export type WorkLog = {
  id: string; user_id: string; log_date: string;
  project_id: string | null; hours: number | null; is_leave: boolean;
  custom_project_name?: string | null; custom_project_code?: string | null;
  category?: WorkCategory; description?: string | null;
  profiles?: { full_name: string };
  projects?: { name: string; project_code: string } | null;
};

export function logProjectName(w: WorkLog) { return w.projects?.name || w.custom_project_name || ''; }
export function isManualProject(w: WorkLog) { return (w.category || 'project') === 'project' && !w.project_id; }
export function logProjectCode(w: WorkLog) { return w.projects?.project_code || w.custom_project_code || ''; }

export type EntryDraft = { tempId: string; category: WorkCategory; description: string; project_id: string; custom_name: string; custom_code: string; query: string; hours: string };

export function newEntryDraft(): EntryDraft {
  return { tempId: crypto.randomUUID(), category: 'project', description: '', project_id: '', custom_name: '', custom_code: '', query: '', hours: '' };
}

export type EntryInput = {
  category: WorkCategory; project_id: string | null; custom_name: string; custom_code: string; description: string; hours: number;
};

export function isDraftReady(d: EntryDraft, opts: { requireHours?: boolean } = {}): boolean {
  const hasTarget = d.category !== 'project' || Boolean(d.project_id) || Boolean(d.custom_name.trim());
  if (!hasTarget) return false;
  if (opts.requireHours === false) return true;
  const hours = Number(d.hours);
  return d.hours !== '' && !isNaN(hours) && hours > 0;
}

export function draftToEntry(d: EntryDraft): EntryInput {
  return {
    category: d.category, project_id: d.project_id || null, custom_name: d.custom_name,
    custom_code: d.custom_code, description: d.description, hours: Number(d.hours),
  };
}

export function buildWorkLogInserts(userId: string, date: string, entries: EntryInput[], hasV4Schema: boolean) {
  return entries.map(e => ({
    user_id: userId, log_date: date, hours: e.hours, is_leave: false,
    ...(hasV4Schema ? { category: e.category, description: e.description.trim() || null } : {}),
    ...(e.category !== 'project'
      ? { project_id: null }
      : e.project_id
        ? { project_id: e.project_id }
        : { project_id: null, custom_project_name: e.custom_name.trim(), custom_project_code: e.custom_code.trim() || null }),
  }));
}

// Replaces every work-log row of the user on that date with `entries` (same as the form always did).
export async function saveDay(client: SupabaseClient, userId: string, date: string, entries: EntryInput[], hasV4Schema: boolean): Promise<{ error: string | null }> {
  const removed = await client.from('work_logs').delete().eq('user_id', userId).eq('log_date', date);
  if (removed.error) return { error: removed.error.message };
  if (!entries.length) return { error: null };
  const { error } = await client.from('work_logs').insert(buildWorkLogInserts(userId, date, entries, hasV4Schema));
  return { error: error?.message ?? null };
}

export type ExistingEntry = EntryInput & { label: string; code: string };

export function workLogToExistingEntry(w: WorkLog): ExistingEntry {
  const category = w.category || 'project';
  const description = w.description || '';
  const label = category === 'project'
    ? logProjectName(w)
    : description ? `${CATEGORY_LABEL[category]}: ${description}` : CATEGORY_LABEL[category];
  return {
    category, project_id: w.project_id, custom_name: w.custom_project_name || '', custom_code: w.custom_project_code || '',
    description, hours: w.hours || 0, label, code: logProjectCode(w),
  };
}
```

Note: the `workLogToExistingEntry` quotation test expects `custom_name: ''` and `custom_code: ''` — the code above satisfies that because the test object has no custom fields.

```ts
// Pure day-timer logic. Durations are always derived from timestamps, so closing
// the app, sleeping or crashing never loses time. No React, no browser globals.
import type { WorkCategory } from './worklog';

export type TimerItem = {
  id: string;
  category: WorkCategory;
  project_id: string | null;
  custom_name: string;
  custom_code: string;
  description: string;
  label: string; // display name captured when the item was added
  code: string;  // project code captured when the item was added ('' if none)
};

export type TimerSegment = { itemId: string; start: number; end: number | null };
export type PendingAway = { start: number; end: number; itemId: string };

export type DayTimerState = {
  version: 1;
  userId: string;
  date: string; // local YYYY-MM-DD of "Mulai hari"
  items: TimerItem[];
  segments: TimerSegment[]; // at most one open segment (end === null)
  status: 'running' | 'paused' | 'review';
  lastSeen: number;
  idleSince: number | null;
  pendingAway: PendingAway | null;
};

export const AWAY_THRESHOLD_MS = 10 * 60_000;
export const HEARTBEAT_MS = 30_000;
export const IDLE_DETECTOR_THRESHOLD_MS = 60_000;

export function localDateStr(ms: number): string {
  const d = new Date(ms);
  const pad = (n: number) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
}

export function createDay(userId: string, now: number): DayTimerState {
  return {
    version: 1, userId, date: localDateStr(now), items: [], segments: [],
    status: 'paused', lastSeen: now, idleSince: null, pendingAway: null,
  };
}

export function currentItemId(state: DayTimerState): string | null {
  return state.segments.find(s => s.end === null)?.itemId ?? null;
}

function closeOpen(segments: TimerSegment[], at: number): TimerSegment[] {
  return segments.map(s => (s.end === null ? { ...s, end: Math.max(at, s.start) } : s));
}

export function addItem(state: DayTimerState, item: TimerItem): DayTimerState {
  if (state.status === 'review') return state;
  return { ...state, items: [...state.items, item] };
}

export function switchTo(state: DayTimerState, itemId: string, now: number): DayTimerState {
  if (state.pendingAway || state.status === 'review') return state;
  if (!state.items.some(i => i.id === itemId) || currentItemId(state) === itemId) return state;
  return {
    ...state,
    segments: [...closeOpen(state.segments, now), { itemId, start: now, end: null }],
    status: 'running', lastSeen: now, idleSince: null,
  };
}

export function pause(state: DayTimerState, now: number): DayTimerState {
  if (state.status !== 'running' || state.pendingAway) return state;
  return { ...state, segments: closeOpen(state.segments, now), status: 'paused', lastSeen: now, idleSince: null };
}

export function resume(state: DayTimerState, now: number): DayTimerState {
  if (state.status !== 'paused') return state;
  const last = state.segments[state.segments.length - 1];
  if (!last) return state;
  return { ...state, segments: [...state.segments, { itemId: last.itemId, start: now, end: null }], status: 'running', lastSeen: now };
}

export function itemTotals(state: DayTimerState, now: number): Record<string, number> {
  const totals: Record<string, number> = {};
  for (const item of state.items) totals[item.id] = 0;
  for (const s of state.segments) totals[s.itemId] = (totals[s.itemId] ?? 0) + Math.max(0, (s.end ?? now) - s.start);
  return totals;
}

export function dayTotal(state: DayTimerState, now: number): number {
  return Object.values(itemTotals(state, now)).reduce((a, b) => a + b, 0);
}

export function formatClock(ms: number): string {
  const total = Math.max(0, Math.floor(ms / 1000));
  const h = Math.floor(total / 3600);
  const m = Math.floor((total % 3600) / 60);
  const s = total % 60;
  return `${h}:${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
}
```

```ts
export function markIdle(state: DayTimerState, since: number): DayTimerState {
  if (state.status !== 'running' || state.idleSince !== null) return state;
  return { ...state, idleSince: since };
}

// Call when the user is active again and when the app loads.
export function detectAway(state: DayTimerState, now: number): DayTimerState {
  if (state.status !== 'running' || state.pendingAway) return { ...state, idleSince: null, lastSeen: now };
  const open = state.segments.find(s => s.end === null);
  // Heartbeats pause while the user is idle, so an idle mark wins over a stale lastSeen.
  const gapStart = state.idleSince ?? (now - state.lastSeen >= AWAY_THRESHOLD_MS ? state.lastSeen : null);
  if (open && gapStart !== null) {
    const start = Math.max(gapStart, open.start);
    if (now - start >= AWAY_THRESHOLD_MS) {
      return { ...state, pendingAway: { start, end: now, itemId: open.itemId }, idleSince: null, lastSeen: now };
    }
  }
  return { ...state, idleSince: null, lastSeen: now };
}

// Call on every heartbeat. While the user is idle we wait for them to come back before asking.
export function tick(state: DayTimerState, now: number): DayTimerState {
  if (state.idleSince !== null) return state;
  return detectAway(state, now);
}

export function cutRange(segments: TimerSegment[], start: number, end: number): TimerSegment[] {
  const out: TimerSegment[] = [];
  for (const s of segments) {
    const sEnd = s.end ?? Infinity;
    if (sEnd <= start || s.start >= end) { out.push(s); continue; }
    if (s.start < start) out.push({ ...s, end: start });
    if (sEnd > end) out.push({ ...s, start: end });
  }
  return out;
}

export type AwayChoice = { type: 'keep' } | { type: 'discard' } | { type: 'move'; itemId: string };

export function resolveAway(state: DayTimerState, choice: AwayChoice): DayTimerState {
  const away = state.pendingAway;
  if (!away) return state;
  if (choice.type === 'move' && !state.items.some(i => i.id === choice.itemId)) return state;
  let segments = state.segments;
  if (choice.type !== 'keep') segments = cutRange(segments, away.start, away.end);
  if (choice.type === 'move') {
    segments = [...segments, { itemId: choice.itemId, start: away.start, end: away.end }].sort((a, b) => a.start - b.start);
  }
  return { ...state, segments, pendingAway: null };
}
```

```ts
export function backToTimer(state: DayTimerState, now: number): DayTimerState {
  if (state.status !== 'review') return state;
  return { ...state, status: 'paused', lastSeen: now };
}

export function isStaleDay(state: DayTimerState, now: number): boolean {
  return state.items.length > 0 && state.date !== localDateStr(now);
}

// A day left open overnight ends at its last sign of activity, then waits in review.
export function closeStaleDay(state: DayTimerState): DayTimerState {
  return { ...state, segments: closeOpen(state.segments, state.lastSeen), status: 'review', idleSince: null, pendingAway: null };
}

export function roundToHalfHour(ms: number): number {
  return Math.round((ms / HOUR_MS) * 2) / 2;
}

export type ReviewRow = ExistingEntry & { key: string; source: 'timer' | 'existing'; trackedMs: number | null };

export function buildReviewRows(state: DayTimerState, now: number, existing: ExistingEntry[]): ReviewRow[] {
  const totals = itemTotals(state, now);
  const existingRows: ReviewRow[] = existing.map((e, i) => ({ ...e, key: `existing-${i}`, source: 'existing', trackedMs: null }));
  const timerRows: ReviewRow[] = state.items.map(item => ({
    key: `timer-${item.id}`, source: 'timer', trackedMs: totals[item.id] ?? 0, hours: roundToHalfHour(totals[item.id] ?? 0),
    category: item.category, project_id: item.project_id, custom_name: item.custom_name, custom_code: item.custom_code,
    description: item.description, label: item.label, code: item.code,
  }));
  return [...existingRows, ...timerRows];
}

export function reviewRowsToEntries(rows: ReviewRow[]): EntryInput[] {
  return rows.filter(r => r.hours > 0).map(r => ({
    category: r.category, project_id: r.project_id, custom_name: r.custom_name,
    custom_code: r.custom_code, description: r.description, hours: r.hours,
  }));
}

export function draftToTimerItem(d: EntryDraft, project: Project | undefined, id: string): TimerItem {
  const description = d.description.trim();
  const isProject = d.category === 'project';
  const label = isProject
    ? project?.name ?? d.custom_name.trim()
    : description ? `${CATEGORY_LABEL[d.category]}: ${description}` : CATEGORY_LABEL[d.category];
  return {
    id, category: d.category,
    project_id: isProject && d.project_id ? d.project_id : null,
    custom_name: isProject && !d.project_id ? d.custom_name.trim() : '',
    custom_code: isProject && !d.project_id ? d.custom_code.trim() : '',
    description, label, code: isProject ? project?.project_code ?? d.custom_code.trim() : '',
  };
}

type ReadStorage = Pick<Storage, 'getItem'>;
type WriteStorage = Pick<Storage, 'setItem'>;
type RemoveStorage = Pick<Storage, 'removeItem'>;

export function storageKey(userId: string) { return `weave.dayTimer.${userId}`; }

export function loadState(storage: ReadStorage, userId: string): DayTimerState | null {
  try {
    const raw = storage.getItem(storageKey(userId));
    if (!raw) return null;
    const parsed = JSON.parse(raw);
    if (!parsed || parsed.version !== 1 || parsed.userId !== userId || !Array.isArray(parsed.items) || !Array.isArray(parsed.segments)) return null;
    return parsed as DayTimerState;
  } catch {
    return null;
  }
}

export function saveState(storage: WriteStorage, state: DayTimerState): boolean {
  try { storage.setItem(storageKey(state.userId), JSON.stringify(state)); return true; } catch { return false; }
}

export function clearState(storage: RemoveStorage, userId: string): void {
  try { storage.removeItem(storageKey(userId)); } catch { /* storage unavailable */ }
}

export const OWNER_KEY = 'weave.dayTimer.owner';
export type OwnerRecord = { tabId: string; at: number };

export function canOwn(record: OwnerRecord | null, tabId: string, now: number): boolean {
  return !record || record.tabId === tabId || now - record.at > HEARTBEAT_MS * 2;
}

export function readOwner(storage: ReadStorage): OwnerRecord | null {
  try {
    const parsed = JSON.parse(storage.getItem(OWNER_KEY) || 'null');
    return parsed && typeof parsed.tabId === 'string' && typeof parsed.at === 'number' ? parsed : null;
  } catch {
    return null;
  }
}

export function writeOwner(storage: WriteStorage, record: OwnerRecord): void {
  try { storage.setItem(OWNER_KEY, JSON.stringify(record)); } catch { /* storage unavailable */ }
}

export function releaseOwner(storage: ReadStorage & RemoveStorage, tabId: string): void {
  if (readOwner(storage)?.tabId !== tabId) return;
  try { storage.removeItem(OWNER_KEY); } catch { /* storage unavailable */ }
}
```

```ts
'use client';

import { useCallback, useEffect, useRef, useState } from 'react';
import {
  addItem as addItemFn, backToTimer as backToTimerFn, canOwn, closeStaleDay, createDay, detectAway, HEARTBEAT_MS,
  IDLE_DETECTOR_THRESHOLD_MS, isStaleDay, loadState, markIdle, pause as pauseFn, readOwner, releaseOwner,
  resolveAway as resolveAwayFn, resume as resumeFn, saveState, clearState, startReview as startReviewFn,
  switchTo as switchToFn, tick, writeOwner, type AwayChoice, type DayTimerState, type TimerItem,
} from '@/lib/dayTimer';

type IdleDetectorLike = EventTarget & {
  userState: 'active' | 'idle' | null;
  screenState: 'locked' | 'unlocked' | null;
  start(opts: { threshold: number; signal: AbortSignal }): Promise<void>;
};
type IdleDetectorCtor = { new (): IdleDetectorLike; requestPermission(): Promise<'granted' | 'denied'> };

export type DayTimer = ReturnType<typeof useDayTimer>;

export function useDayTimer(userId: string) {
  const [state, setState] = useState<DayTimerState | null>(null);
  const [loaded, setLoaded] = useState(false);
  const [now, setNow] = useState(() => Date.now());
  const [isOwner, setIsOwner] = useState(true);
  const [staleNotice, setStaleNotice] = useState<string | null>(null);
  const [tabId] = useState(() => crypto.randomUUID());
  const idleAbort = useRef<AbortController | null>(null);

  // Load once per user; close a day left open overnight, and catch gaps while the app was closed.
  useEffect(() => {
    const t = Date.now();
    let s = loadState(window.localStorage, userId);
    if (s && isStaleDay(s, t)) { setStaleNotice(s.date); s = closeStaleDay(s); }
    else if (s) s = detectAway(s, t);
    setState(s);
    setLoaded(true);
  }, [userId]);

  // Persist every change made by the owning tab.
  useEffect(() => {
    if (!loaded || !isOwner) return;
    if (state) saveState(window.localStorage, state);
    else clearState(window.localStorage, userId);
  }, [state, loaded, isOwner, userId]);

  // Single owner across tabs; other tabs show a read-only notice.
  useEffect(() => {
    const claim = () => {
      const ok = canOwn(readOwner(window.localStorage), tabId, Date.now());
      if (ok) writeOwner(window.localStorage, { tabId, at: Date.now() });
      setIsOwner(ok);
    };
    const release = () => releaseOwner(window.localStorage, tabId);
    claim();
    const id = window.setInterval(claim, HEARTBEAT_MS);
    window.addEventListener('pagehide', release);
    return () => { window.clearInterval(id); window.removeEventListener('pagehide', release); release(); };
  }, [tabId]);

  // Clock for display (1 s) and heartbeat (every HEARTBEAT_MS of state.lastSeen).
  useEffect(() => {
    const id = window.setInterval(() => {
      const t = Date.now();
      setNow(t);
      if (isOwner) setState(s => (s && t - s.lastSeen >= HEARTBEAT_MS ? tick(s, t) : s));
    }, 1000);
    return () => window.clearInterval(id);
  }, [isOwner]);

  const startIdleDetection = useCallback(async (askPermission: boolean) => {
    const Detector = (window as unknown as { IdleDetector?: IdleDetectorCtor }).IdleDetector;
    if (!Detector || idleAbort.current) return;
    try {
      if (askPermission) {
        if ((await Detector.requestPermission()) !== 'granted') return;
      } else {
        const status = await navigator.permissions.query({ name: 'idle-detection' as PermissionName });
        if (status.state !== 'granted') return;
      }
      const controller = new AbortController();
      const detector = new Detector();
      detector.addEventListener('change', () => {
        const t = Date.now();
        if (detector.screenState === 'locked') setState(s => s && markIdle(s, t));
        else if (detector.userState === 'idle') setState(s => s && markIdle(s, t - IDLE_DETECTOR_THRESHOLD_MS));
        else setState(s => s && detectAway(s, t));
      });
      await detector.start({ threshold: IDLE_DETECTOR_THRESHOLD_MS, signal: controller.signal });
      idleAbort.current = controller;
    } catch {
      // Idle detection is optional; sleep/closed gaps are still caught by the heartbeat.
    }
  }, []);

  useEffect(() => {
    void startIdleDetection(false);
    return () => { idleAbort.current?.abort(); idleAbort.current = null; };
  }, [startIdleDetection]);

  const apply = useCallback((fn: (s: DayTimerState, t: number) => DayTimerState) => {
    setState(s => (s ? fn(s, Date.now()) : s));
  }, []);

  return {
    state, now, isOwner, staleNotice,
    dismissStale: () => setStaleNotice(null),
    startDay: () => { setState(createDay(userId, Date.now())); void startIdleDetection(true); },
    addItem: (item: TimerItem, start: boolean) => apply((s, t) => {
      const next = addItemFn(s, item);
      return start ? switchToFn(next, item.id, t) : next;
    }),
    switchTo: (itemId: string) => apply((s, t) => switchToFn(s, itemId, t)),
    pause: () => apply(pauseFn),
    resume: () => apply(resumeFn),
    resolveAway: (choice: AwayChoice) => apply(s => resolveAwayFn(s, choice)),
    startReview: () => apply(startReviewFn),
    backToTimer: () => apply(backToTimerFn),
    finishDay: () => { setState(null); setStaleNotice(null); },
  };
}
```

```ts
'use client';

import { useCallback, useEffect, useState } from 'react';

type DocumentPip = { requestWindow(opts: { width: number; height: number }): Promise<Window> };

function copyStyles(from: Document, to: Document) {
  for (const sheet of Array.from(from.styleSheets)) {
    try {
      const style = to.createElement('style');
      style.textContent = Array.from(sheet.cssRules).map(r => r.cssText).join('\n');
      to.head.appendChild(style);
    } catch {
      if (!sheet.href) continue;
      const link = to.createElement('link');
      link.rel = 'stylesheet';
      link.href = sheet.href;
      to.head.appendChild(link);
    }
  }
}

function syncTheme(target: Window) {
  const theme = document.documentElement.dataset.theme;
  if (theme) target.document.documentElement.dataset.theme = theme;
  else delete target.document.documentElement.dataset.theme;
}

export function usePipWindow() {
  const [supported, setSupported] = useState(false);
  const [pipWindow, setPipWindow] = useState<Window | null>(null);

  useEffect(() => { setSupported('documentPictureInPicture' in window); }, []);

  const open = useCallback(async () => {
    const api = (window as unknown as { documentPictureInPicture?: DocumentPip }).documentPictureInPicture;
    if (!api) return;
    const win = await api.requestWindow({ width: 320, height: 420 });
    win.document.title = 'Weave';
    copyStyles(document, win.document);
    syncTheme(win);
    win.document.body.className = 'pip-body';
    win.addEventListener('pagehide', () => setPipWindow(null));
    setPipWindow(win);
  }, []);

  useEffect(() => {
    if (!pipWindow) return;
    const observer = new MutationObserver(() => syncTheme(pipWindow));
    observer.observe(document.documentElement, { attributes: true, attributeFilter: ['data-theme'] });
    return () => observer.disconnect();
  }, [pipWindow]);

  const close = useCallback(() => { pipWindow?.close(); }, [pipWindow]);

  return { supported, pipWindow, open, close };
}
```

```tsx
'use client';

import { useState } from 'react';
import { X } from 'lucide-react';
import { buildReviewRows, formatClock, reviewRowsToEntries, type ReviewRow } from '@/lib/dayTimer';
import { saveDay, type ExistingEntry } from '@/lib/worklog';
import { supabase } from '@/lib/supabase';
import { showAlert, showStatus } from '@/lib/notify';
import type { DayTimer } from './useDayTimer';

export function DayReview({ t, timer, existing, hasV4Schema, onSent }: {
  t: any; timer: DayTimer; existing: ExistingEntry[]; hasV4Schema: boolean; onSent: () => void;
}) {
  const state = timer.state!;
  const [rows, setRows] = useState<ReviewRow[]>(() => buildReviewRows(state, Date.now(), existing));
  const [sending, setSending] = useState(false);
  const total = rows.reduce((s, r) => s + (r.hours > 0 ? r.hours : 0), 0);

  function update(key: string, patch: Partial<ReviewRow>) {
    setRows(prev => prev.map(r => (r.key === key ? { ...r, ...patch } : r)));
  }

  async function send() {
    setSending(true);
    const { error } = await saveDay(supabase, state.userId, state.date, reviewRowsToEntries(rows), hasV4Schema);
    setSending(false);
    if (error) { showAlert(error); return; }
    timer.finishDay();
    showStatus(t.daySent);
    onSent();
  }

  return (
    <div className="timer-panel">
      <div className="timer-header">
        <span className="worklog-section-label">{t.reviewTitle}</span>
        <span className="timer-total">{state.date}</span>
      </div>
      <div className="review-list">
        {rows.map(r => (
          <div key={r.key} className={`review-row${r.hours > 0 ? '' : ' is-zero'}`}>
            <div className="review-row-head">
              <span>{r.label}</span>
              {r.code && <span className="code-badge">{r.code}</span>}
              {r.source === 'existing' && <span className="hours-badge">{t.alreadyLogged}</span>}
            </div>
            {r.trackedMs !== null && <div className="review-row-meta">{t.tracked}: {formatClock(r.trackedMs)}</div>}
            {hasV4Schema && (
              <input className="field-input" value={r.description} placeholder={t.deskripsi}
                onChange={e => update(r.key, { description: e.target.value })} />
            )}
            <div className="hours-input-wrap">
              <input type="number" min="0" max="24" step="0.5" className="field-input hours-input"
                value={r.hours} onChange={e => update(r.key, { hours: Number(e.target.value) || 0 })} />
              <span className="hours-unit">jam</span>
            </div>
            <button className="btn-remove-entry" title={t.delete} onClick={() => setRows(prev => prev.filter(x => x.key !== r.key))}><X size={14} /></button>
          </div>
        ))}
      </div>
      <p className="review-total">{t.reviewTotal}: {total} jam · {t.reviewZeroHint}</p>
      <div className="timer-actions timer-footer">
        <button className="btn-secondary" disabled={sending} onClick={timer.backToTimer}>{t.backToTimer}</button>
        <button className="btn-primary" disabled={sending} onClick={() => void send()}>{sending ? '…' : t.send}</button>
      </div>
    </div>
  );
}
```

Note: a description edited on a Quotation/Training row changes its saved description; the label stays as captured (it is display only).
